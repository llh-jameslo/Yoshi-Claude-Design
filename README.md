# Yoshi / Fuibo Flower

Interactive prototype of the Yoshi companion app (onboarding + Fuibo Flower home).

## Requirements

- [Node.js](https://nodejs.org/) 20+ (npm included)

## Start the app

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually [http://localhost:5173/](http://localhost:5173/)).

### Other commands

```bash
npm run build    # production build → dist/
npm run preview  # preview the production build
npm run lint     # run Oxlint
```
